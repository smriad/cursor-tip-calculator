# Tip Calculator

A single-page tip calculator built for [Global Hack Week: Hacktoberfest — CHALLENGE 1: Build a Mini App with Cursor](https://www.mlh.com/events/global-hack-week-open-source-90/challenges/01a11d23-3841-86cf-2fa3-5e70600e8f08/submissions/new).

## Run locally

Open `index.html` in any modern browser (no build step).

```bash
open index.html
```

## Features

- Bill amount, tip slider (0–40%), quick presets (10–25%)
- Split between people with live totals
- Dark mode toggle (preference saved in `localStorage`)

## Stack

HTML, CSS, and vanilla JavaScript.
